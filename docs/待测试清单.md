## 已知环境差异

- **Android 15 / API 35**：番茄小说 `com.dragon.read` 7.4.3.32 已观察到 `APP CRASH(NATIVE)`，堆栈涉及 ARM64 原生库与 `libndk_translation.so`，此环境仍不能标记兼容通过。
- **Android 11 / API 30 对照**：同一 APK 出现 `Bad 'ubidi_openSized_66' call` 原生崩溃。固定分辨率未解决该错误，此环境仍不能标记兼容通过。
- **Android 16 / API 36，新默认环境**：已显示番茄欢迎与个人信息说明页；用户自行确认后，后台检测到首页 `MainFragmentActivity` 运行、可见并完成绘制，当次采集没有新的应用崩溃记录。登录、阅读和长时稳定性仍未验收。见 [白屏诊断与修复记录](问题记录-20261103-番茄小说白屏.md)。
- 原 API 35 / 30 AVD 与数据目录保留；没有自动迁移登录、书架或缓存到 API 36。
