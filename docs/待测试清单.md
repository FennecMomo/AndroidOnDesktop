## 本机内存调整为 8GB

按用户要求，本机 `data/settings.json` 的 `EmulatorMemoryMb` 和 API 36 AVD 的 `hw.ramSize` 已从 3072 调整为 8192，并正常停止、重新启动 Android；原配置已备份，未清除应用数据。该参数由现有 0.1.2 支持，无需修改程序或重新发布。以下 3072 MB 记录保留为此前发布时点的历史证据。

必要检查已通过：实际模拟器命令包含 `-memory 8192`，Android `/proc/meminfo` 报告 `MemTotal: 8136436 kB`（系统可用总量略低于配置值），GLES 仍为 NVIDIA GeForce RTX 4070 Ti；正式管理器读到 8192 MB 并成功连接。番茄小说进入可见、已绘制状态，随后观察 10 秒未检测到新崩溃。证据位于 `artifacts/verification/memory-8gb-20261103-170151/`。

**未测试**：8GB 配置下的实际滑动、阅读、输入流畅度和持续使用后的宿主分页情况，不能据此次启动检查认定性能提升。调整前 Windows 可用内存约 4.95 GiB，扩大 Android 内存可能增加宿主分页；未关闭其他应用或修改 Windows 设置。本次仅改变本机配置，程序面向其他电脑的初始默认值仍为 3072 MB。
